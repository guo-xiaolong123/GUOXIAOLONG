# 运河儒风 · 曲阜旅游指南

> 文化旅游赛道 · 赛题二「游客智能讲解与行程定制助手」参赛作品
> 面向曲阜 · 济宁 · 湖区游客的一站式行旅助手 —— 把"看懂"与"怎么走"装进一部手机。

## 🏮 项目简介

依托曲阜儒家文化、济宁运河文化与湖区文旅资源，围绕游客最关心的两件事设计：**看得明白**（智能讲解）与**怎么走**（行程定制）。同时通过一键导出讲解稿、全程连播导览等功能，减轻景区与文旅从业者的重复劳动。

- **零框架纯原生**：HTML + CSS + JavaScript，无构建依赖，秒级加载
- **纯静态可托管**：无需后端与数据库，任意静态托管平台直接部署
- **移动优先设计**：手机端体验最佳，桌面宽屏自动切换双栏/多列布局
- **离线友好**：讲解语料、问答检索、足迹收藏全部本机运行，不联网也能用

## ✨ 核心功能

### 智能讲解 —— 看得明白
- **到站讲解**：每站给出"到站先看"观察线索与讲解要点（20 站站点库）
- **随走随问**：本地语料检索，时间 / 票价 / 美食 / 住宿 / 交通 / 演出 / 机位等即问即答
- **拍照识景**：选示范样本或拍现场照片，识别后直接进入该站讲解
- **分人群话术**：自由行 / 亲子 / 研学三套讲解一键切换
- **多语种**：中文 / English / 日本語，讲解与路书同步切换，支持浏览器语音朗读

### 行程定制 —— 怎么走
- **按条件生成路书**：兴趣（曲阜礼乐 / 运河市井 / 湖岸生灵）× 时间 × 同行人 × 出行情境
- **自动排程**：计入停留、转场与休息时间，亲子模式每两站自动留补水休息
- **雨天 / 节假日备选线**：一键切换室内站点池或避峰站点池
- **一键连播导览**：路书按站序自动朗读全程，从业者带队"解放双手"
- **导出带队讲解稿**：含时间轴、讲解词、亲子话术、研学任务与中英日摘要

### 游戏化与传播
- **成就系统「圣城印记」**：14 枚徽章（三孔集章、运河访客、闯关状元……），解锁弹提示，「我的」页成就墙点亮
- **论语灵签**：竹签摇动动画，12 支签文对应旅行建议
- **儒学闯关**：12 道题，答对金花庆祝、答错震动讲解，最高分本机记录
- **打卡海报**：Canvas 本机绘制 20 站 × 4 季国风海报，可下载分享
- **行装清单 / 旅费速算 / 节庆日历**：出行前的"最后一公里"

## 🚀 部署方式

```bash
# 任选其一
# 1. 阿里云 ECS + Nginx：把整个目录放到站点根目录即可
# 2. GitHub Pages / 任意静态托管：直接上传全部文件
```

- **入口**：`index.html`（自动跳转 `home.html`）
- **HTTPS 提示**：启用 HTTPS 后手机端可获得卫星级精确定位（HTTP 下自动降级为 IP 城市级 + 手动选点）
- **地图 Key**：`map.html` 中已配置高德开放平台 Web端(JSAPI) Key，可替换为你自己的 Key

## 🗺 定位策略（三级降级）

1. **GPS 精确定位**：HTTPS + 手机端，误差 10~50 米
2. **IP 城市级定位**：浏览器定位失败或误差过大时自动校准降级
3. **手动选点兜底**：点击地图任意位置设为"我的位置"，距离计算同样精准

> 电脑端无 GPS 硬件，建议点 📍 后在地图上手动点选真实位置；
> 定位跳转到异地城市后，点 🏛️ 一键回到圣城视野。

## 🛡 数据与隐私

足迹、收藏、常用路线、成就与清单进度**仅保存在本机浏览器**（localStorage），免登录、不上传任何个人信息。
