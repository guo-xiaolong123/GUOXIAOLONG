# 个人主页

这是一个简单的个人主页示例，包含 `index.html`、`styles.css` 和 `script.js`。

## 使用说明

1. 将你的名字、简介、邮箱和 Gitee 链接替换为你的真实信息。
2. 打开 `index.html` 预览个人主页。
3. 提交到 Gitee：
   ```powershell
   git add .
   git commit -m "添加个人主页"
   git push
   ```

## 文件说明

- `index.html`：个人主页页面
- `styles.css`：页面样式文件
- `script.js`：页面交互脚本
