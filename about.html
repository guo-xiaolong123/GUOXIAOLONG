定位使用建议

📍 自动定位 · 最佳实践
📱
手机端：开启移动数据流量

自动定位模式下，建议使用手机并开启移动数据（蜂窝网络）。GPS 卫星定位精度可达 10~50 米，室内请靠近窗口。

🖥️
电脑端：建议手动定位

台式电脑通常无 GPS 硬件，浏览器仅能通过 IP 估算位置，可能无法准确判定（偏差可达数百公里）。建议点 📍 定位后在地图上手动点选真实位置，距离计算同样精准。

🔑
权限须知

浏览器弹窗"是否允许获取位置"请选择允许；若曾拒绝，需在浏览器设置中恢复该网站的位置权限。

ℹ️ 为什么有精度差异？浏览器安全模型规定：仅 HTTPS 网页可调用卫星级精确定位；IP 定位受运营商出口 IP 登记影响。本应用采用"GPS → 自动校验降级 → 手动选点"三级策略，保证全场景可用。

技术架构

🗺️高德 JSAPI 2.0

官方 Web 定位 + 城市级 IP 定位双通道，key + 安全密钥配置

🧭三级定位降级

GPS 精确定位 → IP 定位（可信度校验）→ 手动选点兜底

📐Haversine 测距

球面三角公式计算直线距离，GCJ-02 坐标系原生支持

📱响应式布局

媒体查询 + 动态根字号，手机单栏 / 电脑双栏自动切换

🎨零框架纯原生

单文件应用，原生 JS + CSS 动画，无构建依赖，秒级加载

🛡️健壮性设计

SDK 加载失败自动降级提示，底图不可用时列表与讲解照常可用

🧠规则式行程引擎

💬本机语料问答
